A 3D bush-plane flight game (Three.js) in a procedural river-canyon valley: three missions (Ring Run, Canyon Pass, Touchdown), a pure-math flight model with stall, fuel burn and damage, a glass-cockpit HUD, chase and cockpit cameras, and WebAudio engine/wind/ring sounds.

## Run it

```sh
node main.ts
```
